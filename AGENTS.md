# Project instructions

- Keep SpendWise easy to explain as a college project. Prefer straightforward React components and Express routes.
- Use JavaScript, React, Express, Mongoose, and plain CSS as the project grows.
- Keep frontend code in `frontend/` and API code in `backend/`.
- Store local secrets and connection strings in `.env` files. Never commit `.env` files.
- Preserve existing working functionality and avoid adding libraries without a feature need.
- Do not implement authentication, payments, bank integrations, or AI features.
